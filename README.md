# Activation Gradient Slope as an Indicator of Decision Certainty — Reproduction Code

Code to independently reproduce every experiment, figure, and table in:

> Elakkat D. Gireesh and Varadraj P. Gurupur, *"Activation Gradient Slope as
> an Architecture-General Indicator of Decision Certainty in Deep Neural
> Networks: Cross-Architecture Evidence, Baseline Benchmarking, and a
> Physics-of-Information Framework,"* Department of Electrical and Computer
> Engineering, University of Central Florida, working paper, August 2026.

## What's being tested

The paper's core claim: across four architecturally distinct deep networks —
two CNNs (MNIST, Fashion-MNIST), an MLP (CHB-MIT EEG seizure detection), and
a transformer (DistilBERT on SST-2) — the OLS slope of mean absolute
activation-gradient magnitude across layers is **negatively correlated**
with a softmax-derived Certainty Index (CI), consistent with the predicted
functional form `S_i ∝ (1 − CI²)`.

**This is a self-critical paper, and this repo reproduces that framing
faithfully, not just the favorable numbers.** Beyond the four-architecture
correlation, the paper reports:
- A **negative result**: an earlier draft's "slope-anomaly" adversarial
  detector (claimed to beat plain CI at flagging adversarial inputs) did
  **not** replicate on a retrained checkpoint or on two additional
  architectures, and is the weakest of five detectors tested across an
  FGSM/PGD epsilon sweep. The code here reproduces that stress test and
  prints its actual measured AUCs each run rather than assuming an outcome.
- Direct baseline benchmarking against softmax entropy, margin, and
  MC-dropout variance — the gradient slope is competitive but **not
  uniformly the best** detector.
- An empirical audit of the theory's own mean-field assumption (uniform
  per-layer Jacobian spectral norm), which holds well only for the shallow
  EEG MLP and considerably less well for the CNNs and DistilBERT.

If you're here to independently verify the paper, this is the intended
entry point — every number in the paper's tables is regenerated by one of
the scripts below, and every script prints its own statistics rather than
hardcoding the paper's reported values.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Requires Python 3.9+. A GPU is optional — the CNN/MLP training and
DistilBERT inference all run on CPU, just slower (see runtime notes below).

MNIST and Fashion-MNIST auto-download via `torchvision` on first run.
DistilBERT and its SST-2/QQP data auto-download from HuggingFace on first
run (needs internet access; the model + tokenizer are a few hundred MB).
The CHB-MIT EEG data is **not** auto-downloaded or bundled — see
[`data/README.md`](data/README.md).

## Reproduction pipeline

All scripts live in `scripts/` and write their outputs (trained weights,
`.npz` data files, `.png` figures) alongside themselves. Run from the repo
root:

```bash
# Steps 1-4 and 6 are independent of each other; run in any order.
python scripts/gradient_effect_mnist.py         # 1. CNN on MNIST
python scripts/gradient_effect_fmnist.py        # 2. CNN on Fashion-MNIST
python scripts/gradient_effect_mit_eeg.py       # 3. MLP on CHB-MIT EEG (needs data/README.md setup)
python scripts/gradient_effect_distilbert.py    # 4. DistilBERT on SST-2
python scripts/gradient_effect_adversarial.py   # 6. FGSM/PGD stress test on MNIST (trains its own MNIST CNN if step 1 wasn't run)

# Step 5 needs 1-4 to have completed:
python scripts/make_unified_figures.py          # 5. Unified per-architecture figures + comparison chart

# Steps 7-9 need 1-4 to have completed. Step 7 additionally needs 2, 3, and 6
# (it reloads fmnist_cnn_trained.pth, eeg_mlp_trained.npz, and the EEG X_test
# array saved by step 3):
python scripts/gradient_effect_adversarial_extended.py  # 7. Adversarial stress test on Fashion-MNIST + EEG
python scripts/gradient_effect_baselines.py              # 8. Baseline detector comparison + partial correlation
python scripts/gradient_effect_jacobian_norms.py          # 9. Jacobian spectral-norm validation
```

`gradient_effect_shared_baselines.py` is a utility module imported by
scripts 6-9, not run directly.

### Runtime notes

- Steps 1-2 (MNIST/Fashion-MNIST CNN training): a few minutes each on CPU.
- Step 3 (EEG MLP): pure NumPy, under a minute, but needs the EEG data set up first.
- Step 4 (DistilBERT): a few minutes on CPU for ~500 forward+backward passes;
  much faster on GPU.
- Steps 6-9 reload trained models and run additional forward/backward
  passes (power iteration, MC-dropout, adversarial generation) — expect
  these to take longer than steps 1-4, particularly step 9's DistilBERT
  Jacobian power iteration and step 8's DistilBERT MC-dropout pass on CPU.

## Expected results

From the paper's Table "cross-architecture slope–CI correlation summary":

| Architecture              | Modality      | r        | R²     | p-value              | n    |
|----------------------------|---------------|---------:|-------:|-----------------------|-----:|
| CNN (MNIST)                | Image         | −0.768   | 0.590  | 1.1×10⁻¹⁹⁵            | 1000 |
| CNN (Fashion-MNIST)        | Image         | −0.835   | 0.698  | 1.4×10⁻²⁶¹            | 1000 |
| MLP (CHB-MIT EEG)          | EEG signal    | −0.902   | 0.813  | 5.3×10⁻⁷⁴             | 200  |
| DistilBERT (SST-2)         | Natural lang. | −0.716   | 0.512  | 1.0×10⁻⁷⁹             | 500  |

All four should show `r < 0` (the "sparse encoding regime"). Exact values
will vary slightly run-to-run (random weight init, data shuffling, and — for
EEG — the specific preprocessed pickle you provide), but the sign and
approximate magnitude should replicate.

For the adversarial stress test (step 6), expect the slope-anomaly detector
to **not** outperform CI — see the paper's Table "adv-stress" and the
"Interpretation" block each run of `gradient_effect_adversarial.py` prints.
